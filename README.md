# Mae Jane Mantawil — Portfolio

A responsive static portfolio website for Mae Jane Mantawil.

## Files
- `index.html` — main website
- `style.css` — design and responsive styling
- `script.js` — mobile menu and portfolio filters
- `assets/` — add your portfolio images and CV here

## Before publishing
1. Replace the sample portfolio cards with your actual design images.
2. Replace `YOUR-EMAIL@example.com` with your email.
3. Update the Facebook, LinkedIn, and Behance links.
4. Put your CV PDF at `assets/Mae-Jane-Mantawil-CV.pdf`.

## Deploy
This is a static website and can be deployed directly to Vercel from GitHub.
